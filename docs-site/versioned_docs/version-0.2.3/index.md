# neoOMSI documentation

Guides for playing neoOMSI, hosting multiplayer sessions, and creating HTML textures.

neoOMSI is a 64-bit reimplementation of OMSI 2. It requires an installed copy of OMSI 2 and does not include the game's maps, vehicles, or other content.

The documentation opens on **0.2.3 Stable**. Use the version menu to switch to the current development guide. Development builds may change or regress before release.

## Choose a guide

- [Player guide](player/user-guide.md): installation, controls, gameplay options, and mods.
- [Linux controller axes](player/linux-controller-axes.md): wheel, pedal, and gamepad axis settings.
- [Dedicated server](server.md): run a headless server and configure multiplayer.
- [HTML textures](creators/html-textures.md): create a vehicle or scenery dashboard in HTML, CSS, and JavaScript.
- [Compatibility](compatibility.md): what neoOMSI aims to support and how to report a problem.

For downloads, release notes, and performance-report privacy, visit [neoomsi.com](https://neoomsi.com/).
